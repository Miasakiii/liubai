# 轻量社群暗示

> 不孤独，但不被打扰。

---

## 设计理念

暂停实验室有「共修」模式——一群人同时开始一个练习，有进度同步感。留白做减法：只暗示「不孤单」，不制造社交压力。

**核心原则：**

- 只展示数字，不展示身份
- 不互动、不评论、不点赞
- 一句话带过，不喧宾夺主
- 让人觉得「不孤单」，但不觉得「被监视」

---

## 触发场景

### 场景 1：听完白噪音后

**当前设计：**
```
听完今天的"不好"就留在这里了。明天见。
```

**加入社群暗示后：**
```

听完今天的"不好"就留在这里了。明天见。

**加入社群暗示后：**

做完就好。明天见。
```

### 场景 3：选择"今天不想说"后

```

**加入社群暗示后：**

**当前设计：**
```

## 文案模板

### 通用模板

```
今天有 {count} 人也{action}。
```

### 动作映射

| 用户行为 | 文案 |
|---------|------|
| 听白噪音 | 今天有 {count} 人也选择了听{白噪音类型} |
| 做呼吸引导 | 今天有 {count} 人也做了呼吸引导 |
| 选择"今天不想说" | 今天有 {count} 人也没说话 |
| 深夜打开 | 现在有 {count} 人也醒着 |
| 情绪输入 | 今天有 {count} 人也说了{情绪} |

## 实现方案

### 方案 1：后端聚合（推荐）

```javascript
// 后端 API
app.get('/api/social-hint', async (req, res) => {
  const { type, value } = req.query;

  const count = await getDailyCount(type, value);

  res.json({
    count: count,
    message: generateHintMessage(type, value, count)
  });
});

// 前端调用
async function showSocialHint(type, value) {
  const response = await fetch(`/api/social-hint?type=${type}&value=${value}`);
  const data = await response.json();

  showHint(data.message);
}
```

### 方案 2：前端缓存 + 定时更新

```javascript
// 前端缓存
const socialHintCache = {
  lastUpdate: null,
  data: null
};

// 每小时更新一次
async function updateSocialHint() {
  const now = new Date();
  if (socialHintCache.lastUpdate &&
      now - socialHintCache.lastUpdate < 3600000) {
    return socialHintCache.data;
  }

  const response = await fetch('/api/social-hint/summary');
  socialHintCache.data = await response.json();
  socialHintCache.lastUpdate = now;

  return socialHintCache.data;
}
```

## 显示规则

### 显示条件

- 用户已使用至少 3 天（新用户不显示，避免压力）
- 不是第一次打开（第一次需要安静的个人体验）
- 不在「7 天留白练习」中（练习期间保持个人空间）

### 显示频率

- 每天最多显示 2 次社群暗示
- 不连续显示（避免刷屏感）
- 优先在「完成」后显示（白噪音结束、呼吸完成）

### 不显示场景

- 用户主动关闭「社群暗示」功能
- 用户使用时间 < 3 天
- 在「7 天留白练习」中
- 在月度回顾页面

### 样式

- 位置：白噪音播放器下方，或呼吸引导下方
- 动画：淡入，不抢焦点
- 不可点击（纯展示）

## 隐私保护

### 数据匿名

- 只统计聚合数据，不记录个人行为
- 不展示「谁」在听，只展示「多少人」在听
- 不做「在线状态」功能

### 用户控制

- 设置页可关闭「社群暗示」功能
- 默认开启，但不强制
- 关闭后不再显示任何社群相关内容

## 设计备忘

**不做：**

- ❌ 用户头像/昵称展示
- ❌ 「谁在听」功能
- ❌ 在线状态指示灯
- ❌ 评论/点赞/分享
- ❌ 「一起听」功能
- ❌ 排行榜

**做：**

- ✅ 聚合数字展示
- ✅ 一句话暗示
- ✅ 可关闭功能
- ✅ 安静的显示方式

## Prompt 设计

### System Prompt（社群暗示文案生成）

```
你是「留白」的社群暗示生成器。

规则：
1. 用一句话告诉用户有多少人也在做同样的事
2. 不要过度渲染，不要煽情
3. 语气安静，像一个安静的数字
4. 不要问用户感受，不要引导互动
```

### 示例输出

- 今天有 327 人也选择了听雨声。
- 现在有 43 人也醒着。
- 今天有 89 人也做了呼吸引导。
- 今天有 156 人也没说话。
