# 7 天留白练习

> 不是打卡，不是任务。只是试试看。

---

## 设计理念

暂停实验室有「21 天情绪管理」等结构化课程。留白做减法——7 天，每天 2 分钟，够了就好。

**核心原则：**

- 不强调「坚持」「完成」「打卡」
- 中途断了没关系，随时可以重新开始
- 完成后给一句安静的总结，不是勋章
- 7 天太短？那就 3 天。留白的本质是「够了就好」

---

## 练习内容

### 第 1 天：来就好

```
今天只需要做一件事：选一个表情。

不用想太多。它代表你现在的心情就够了。

选完就结束。明天见。
```

**设计意图：** 零门槛入口，建立"来就好"的习惯。
**理论依据：** 行为激活——最小行动打破回避循环。

---

### 第 2 天：听一会儿

```
选一个表情，然后听一段白噪音。

90 秒。什么都不用做，听就行。

雨声、海浪、壁炉、风铃、深夜书店——选一个。
```

**设计意图：** 引入感官体验，建立与环境的连接。
**理论依据：** 环境心理学——自然声音降低皮质醇水平。

---

### 第 3 天：呼吸

```
选一个表情，然后做一次呼吸引导。

吸……屏住……呼。
4 秒、7 秒、8 秒。

就一次。够了。
```

**设计意图：** 引入身体觉察，从感官到呼吸。
**理论依据：** 迷走神经刺激——延长呼气激活副交感神经。

---

### 第 4 天：看看窗外

```
选一个表情，然后看窗外 30 秒。

不用想什么。就看。
天在，云在，你也在。

看完就好。
```

**设计意图：** 从内在觉察扩展到外在环境。
**理论依据：** 注意力恢复理论（ART）——自然景观恢复定向注意力。

---

### 第 5 天：喝杯水

```
选一个表情，然后去接一杯温水。

站着喝，别坐着。
认真感受水的温度。

喝完就好。
```

**设计意图：** 引入身体照顾，从心理到生理。
**理论依据：** 躯体标记假说——身体照顾行为向大脑发送"安全"信号。

---

### 第 6 天：写一件事

```
选一个表情，然后写下今天的一件小事。

不用是大事。"今天喝了杯好喝的咖啡"就够了。

写下来，就好。
```

**设计意图：** 引入表达性写作，从接收到输出。
**理论依据：** 表达性写作——书写帮助情绪调节和认知加工。

---

### 第 7 天：回顾

```
选一个表情。

这是你留白的第 7 天。
你来了 7 次。每次只需要 2 分钟。

不用总结，不用感悟。
你留了 7 天的白。这就是照顾自己。
```

**设计意图：** 仪式感收尾，不强调成就，强调过程本身。
**理论依据：** 自我效能感——完成感来自行动本身，而非结果。

## 状态管理

### 进度记录（LocalStorage）

```json
{
  "practice": {
    "startDate": "2026-06-07",
    "currentDay": 3,
    "completedDays": [1, 2, 3],
    "status": "active"
  }
}
```

### 状态流转

```
未开始 → 进行中 → 已完成
                → 已中断（超过 2 天未练习）
                → 已放弃（用户主动退出）
```

### 中断处理

- 超过 2 天未练习：显示"好久不见，要重新开始吗？"
- 不批评、不追问、不说"你中断了"
- 随时可以重新开始，不保留旧进度

## 设计备忘

**不做：**

- ❌ 打卡日历
- ❌ 连续天数统计
- ❌ 成就徽章
- ❌ 分享功能
- ❌ "你坚持了 X 天"的文案

**做：**

- ✅ 安静的进度提示（第 X 天 / 7）
- ✅ 每天的练习内容清晰
- ✅ 完成后一句安静的总结
- ✅ 随时可以退出，不追问原因
