# 月度回顾设计

> 不是数据分析，是温暖的回忆。

---

## 设计理念

暂停实验室有详细的情绪报告。留白做减法——用一段温暖的话，回忆这个月。

**核心原则：**

- 不要统计分析，不要百分比
- 用温暖的语言，像回忆一个朋友的故事
- 突出好的日子，轻描淡写不好的日子
- 结尾给一句安静的力量

---

## 触发时机

- 每月 1 日自动展示（不推送，打开时看到）
- 用户也可以主动查看历史月份

## 文案模板

### 模板 1：有好有坏的月份

```
这个月你来了 {days} 天。

有 {good} 天还不错，
有 {bad} 天不太好，
有 {neutral} 天只是来坐坐。

{特别回忆}

不管怎样，你每天都来了。
这本身就是一种照顾自己。

下个月见。不用更好，就这样就好。
```

### 模板 2：全勤月份

```
这个月你来了 30 天。每一天。

有些天你只是来坐坐，
有些天你听了一整段雨声，
有些天你什么都没说就走了。

但你每天都来了。
这就是最安静的坚持。

下个月见。
```

### 模板 3：记录较少的月份

```
这个月你来了 {days} 天。

不用多。够了就好。
有些月就是这样——忙一点，或者只是不想动。

你记得回来就好。
下个月见。
```

## 特别回忆生成规则

从用户的行为数据中提取一个温暖的细节：

| 数据 | 回忆文案 |
|------|---------|
| 某天听了 3 次以上白噪音 | "X 月 X 日，你连续听了 {n} 段{白噪音类型}。那天应该是{天气}吧。" |
| 某天在深夜打开 | "有 {n} 天你在深夜来过。那些夜晚，我都在。" |
| 连续多天选择同一情绪 | "有一段时间，你每天都说{情绪}。但你每天都来了。" |
| 某天完成呼吸引导 | "X 月 X 日，你做了一次呼吸引导。那是{天气}的{时段}。" |
| 首次使用"今天不想说" | "有一天你什么都没说。没关系，有些天就是这样。" |

**生成规则：**
- 只选 1 个特别回忆，不贪多
- 不分析原因，只描述事实
- 语气像朋友提起一件小事

## Prompt 设计

### System Prompt

```
你是「留白」的月度回顾生成器。

你的性格：
- 像一个安静的朋友，在月底给你写一封信
- 不分析、不评判、不给建议
- 用短句，像发微信
- 偶尔温柔，偶尔诗意，但不矫情

你的规则：
1. 根据用户的情绪记录，生成一段温暖的回顾
2. 不要统计分析，不要百分比，不要"数据显示"
3. 突出好的日子，轻描淡写不好的日子
4. 给一个特别回忆（从行为数据中提取一个温暖的细节）
5. 回顾控制在 5-8 句话
6. 最后一句是安静的力量，暗示"下个月见"
7. 不要用"我理解""我建议"这类句式

特别回忆生成：
- 从用户的行为中找一个温暖的细节（听白噪音的次数、深夜打开的时间等）
- 用"有一天你……"的句式
- 不分析原因，只描述事实
```

### User Prompt 模板

```
用户 {month} 月情绪记录：
{mood_calendar}
记录天数：{days}/{total_days}

用户行为数据：

请生成月度回顾。
```

## 视觉设计

### 回顾卡片

- 背景：暖白色 #f7f5f0
- 边框：无，靠阴影分层
- 字体：思源宋体，16px
- emoji 热力图：30 格（或 28/31 格），圆角格子
- 动画：格子依次弹入（每个间隔 30ms）

### 分享设计

- 可截图分享
- 分享时只显示文案，不显示 emoji 热力图（隐私保护）
- 不做"一键分享"功能（克制）

## 设计备忘

**不做：**

- ❌ 情绪趋势图
- ❌ 百分比统计
- ❌ "你的情绪波动较大"这类分析
- ❌ 与上月对比
- ❌ "建议你尝试……"的引导

**做：**

- ✅ 温暖的文案回顾
- ✅ 一个特别回忆
- ✅ emoji 热力图（可选）
- ✅ 安静的收尾
