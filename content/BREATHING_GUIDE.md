# 呼吸引导扩展

> 呼吸是最简单的自我照顾。

---

## 设计理念

留白目前只有 4-7-8 呼吸。可以扩展到 2-3 种，但不要太多——选择本身就是压力。

**核心原则：**

- 保持 4-7-8 作为默认
- 新增 2 种进阶呼吸
- 每种都配简短的引导文字
- 不需要语音，视觉引导足够

---

## 呼吸类型

### 1. 4-7-8 呼吸（默认）

**适用场景：** 焦虑、入睡困难、需要平静

**节奏：**
- 吸气：4 秒
- 屏住：7 秒
- 呼气：8 秒

**引导文字：**
```
吸……
屏住……
呼……
```

**原理：** 延长呼气激活迷走神经，降低心率。

---

### 2. Box Breathing（方形呼吸）

**适用场景：** 需要专注、压力大、需要稳定

**节奏：**
- 吸气：4 秒
- 屏住：4 秒
- 呼气：4 秒
- 屏住：4 秒

**引导文字：**
```
吸……
屏住……
呼……
屏住……
```

**原理：** 等比例呼吸帮助神经系统回到平衡状态。
**使用者：** 美国海军海豹突击队用于高压环境。

---

### 3. 生理叹息（Physiological Sigh）

**适用场景：** 快速缓解紧张、需要立即平静

**节奏：**
- 吸气：正常吸
- 再吸：补一小口
- 呼气：长呼

**引导文字：**
```
吸……
再吸一点……
慢慢呼出来……
```

**原理：** 双重吸气重新打开塌陷的肺泡，长呼气快速激活副交感神经。
**特点：** 只需 1-3 次，效果最快。
**来源：** 斯坦福神经科学家 Andrew Huberman 的研究。

### 圆圈动画

- 吸气：圆圈放大（4 秒）
- 屏住：圆圈保持（4/7 秒）
- 呼气：圆圈缩小（4/8 秒）
- 动画曲线：ease-in-out

## 引导文案

### 4-7-8 呼吸

**开始：**
```
跟着这个节奏，做 3 轮。
不用想什么，只管呼吸。
```

**每轮：**
```
吸……（4 秒）
屏住……（7 秒）
呼……（8 秒）
```

**完成：**
```
做完就好。
今天的不好，就留在这里了。
```

---

### 方形呼吸

**开始：**
```
跟着这个节奏，做 4 轮。
像一个方形：吸、屏、呼、屏。
```

**每轮：**
```
吸……（4 秒）
屏住……（4 秒）
呼……（4 秒）
屏住……（4 秒）
```

**完成：**
```
稳定了。
不管外面怎样，你找到自己的节奏了。
```

---

### 生理叹息

**开始：**
```
做 3 次就够了。
这是最快让自己平静下来的方法。
```

**每次：**
```
吸……
再吸一点……
慢慢呼出来……
```

**完成：**
```
好了。
一次就够了。
```

## Prompt 设计

### 呼吸类型推荐

```
用户情绪：{mood_emoji}
时间：{time}

请推荐一种呼吸类型，并简要说明为什么。

可选类型：
1. 4-7-8 呼吸 — 焦虑、入睡困难
2. 方形呼吸 — 需要专注、压力大
3. 生理叹息 — 快速缓解紧张

规则：
- 只推荐 1 种
- 用一句话说明原因
- 不要说教，像朋友随口一提
```

### 示例输出

**输入：** 😔 | 晚上 11:30

**输出：**
```
推荐：4-7-8 呼吸
原因：晚上了，这个最帮你放松。
```

**输入：** 😫 | 下午 2:00

**输出：**
```
推荐：生理叹息
原因：快速做 3 次，马上就能缓过来。
```

## 设计备忘

**不做：**

- ❌ 语音引导（保持安静）
- ❌ 复杂的呼吸类型（超过 3 种）
- ❌ 呼吸数据分析
- ❌ 呼吸排行榜

**做：**

- ✅ 视觉引导（圆圈动画）
- ✅ 简短的文字提示
- ✅ 安静的完成语
- ✅ 可选轮数
